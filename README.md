## Application: Unit Dose Calculator (Beta)

This app is designed for doctors specialising in emergency care within a hospital. This includes A&E doctors, emergency medicine specialists and emergency physicians.

The app was developed in response to the need to automate the process and reduce response times, so that patients can be dispensed the correct dose of medication based on their weight.

### App features:
- Specify the name of the medicine to be administered.
- Specify the form of the medicine.
- Specify the time for each dose of the medicine.

### Features dev:
- Boostrap 5.
- CSS.
- JavaScript.
- Sweetalert.

### Local Development
#### How to use the software:

Clone the repository and open the project in your favourite code editor.

You’ll finally be able to use the Unit Dose calculator (Beta)
